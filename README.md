# 时间便签

**把每天几点到几点的工作安排，变成看得见的长期积累。**

时间便签是 SwiftUI / AppKit 制作的 macOS 原生软件，不是网页外壳。不需要账号，工作、目标和进展保存在本机。

> **0.1.2 是公开预览版，不是功能全部完成的稳定版。严格提醒尚未启用，请不要用它代替重要闹钟。**

## 下载与打开

前往 [v0.1.2 macOS Release](https://github.com/Keng0nion/timenote/releases/tag/v0.1.2)，下载：

- `TimeNote-0.1.2-macOS-arm64.dmg`：打开后将“时间便签”拖到“应用程序”。
- `TimeNote-0.1.2-macOS-arm64.zip`：解压后获得相同应用，也可以放在自己选择的文件夹。
- `SHA256SUMS.txt`：用于核对下载文件是否完整。

**仅 Apple Silicon（M 系列芯片），不支持 Intel。** 构建目标是 macOS 14.0 及以上，目前只在 macOS 26.6.2 / Apple Silicon 验证，其他系统版本和其他 Mac 尚未实测。

**没有 Apple 开发者签名或公证。** 包内的临时签名只检查文件完整性；从网上下载后，macOS 可能阻止打开。请保留系统提示，可在仓库反馈；不要关闭 Gatekeeper、移除隔离属性或修改系统安全策略来绕过检查。

从 0.1 / 0.1.0 / 0.1.1 换用此版前，先导出备份，再完全退出旧应用；不要同时运行两份。此版沿用相同数据位置，不需要搬动数据库，不含示例工作。

## 从第一项工作开始

1. **安排工作**：点“新增工作”，写名称和日期，再填“每天几点到几点”。计划分钟数自动计算，不是实际计时。分类可不填。
2. **重复安排**：支持每天、工作日、自选周几，并指定结束日期。跨午夜勾选“次日结束”，如 `23:30` 至次日 `00:45`。
3. **记录进展**：点左侧圆圈记为完成，或点“未记录／百分比”填写 `0–100` 和可选备注。未来日期不能提前填成绩。
4. **修正与历史**：工作右侧“…”可查看追加历史或撤销最后一次手动记录。尚未开始、没有历史的工作可修改安排；先看对比，再确认。
5. **长期目标**：先写目标，再点“安排工作”新建，或点 **“加入已有工作”** 从每日清单选择；可搜索名称、分类或日期。**同一重复安排只显示一次，作为推进目标的持续行动**，每天仍分别记录。每日任务的“…”也可 **“加入长期目标”**，已有归属时可整组调整或移出。不复制、不重复统计；软件不擅自排期，也不把行动的进展当成整个目标的完成率。
6. **看积累**：在“积累与回顾”查看日历、趋势、上周分类与上月整体回顾，点击某天可回到清单。页面可以向下滚动。
7. **备份**：在“设置与备份”导出 JSON。导入先预览，确认后合并；相同内容跳过，同编号存在差异则整批拒绝，不覆盖记录。

修改开始时间会尽量平移结束时间、保持上一次有效时长；结束时间可以单独改。无效或未填完的时间不会自动保存。

### 将重复工作作为持续行动

- 例如30天的“每日学习”和30天的“每日阅读”，选择窗口只显示两项行动，不再铺开60行日期。按名称、分类或其中一天搜索，选中的仍是完整一组。
- **加入、换目标和移出都会处理整组已安排日期，包含过去、今天和未来。** 保存前显示原归属、新归属和受影响次数；日期、时段、进度、备注与历史都不改。单次工作仍只操作自身，移出目标不删除每日工作。
- 目标内部同样按行动显示。完成天数指截至今天、当天这组工作全部达到100%；已记录天数包含部分进展，未记录单列，未来日期不算漏记。点“每日记录”回到今日或最近安排的日期。
- 升级不会自动整理0.1.1留下的零散归属。部分日期已经加入时，会提示本目标已关联多少次；通过“加入已有工作”选择整组，核对原归属后再确认。旧日期属于其他目标的，也会随本次确认移出原目标。
- 分组依据原来的重复安排，不只看名字：另建的同名安排不会误合并。没有生成的未来日期不会自动新增，也不会把后来另建的同名工作自动纳入。
- 选中后还没有保存，或按 Esc 取消，都不会改数据。期间任何成员新增、删除、归属或进度发生变化，保存会整组拒绝；取消后重新打开再选择，不覆盖新记录。
- 数据库结构和原生JSON版本1不变，兼容0.1.0／0.1.1。**关联前的旧备份若含同编号、不同归属的任务，导入会因冲突停止**，不会覆盖新归属；请保留旧备份，并导出整理后的最新备份。

### 快捷入口与退出

- 应用内 `⌘N` 新增工作，`⌘,` 打开设置，表单可用 Esc 取消。
- 设置里可以录入“打开时间便签”和“新增工作”的全局快捷键，默认不占用组合；只在程序运行时有效。跨应用实际按键触发尚未验收。
- 关闭窗口后，菜单栏入口仍在，点击可重新打开。**关窗口不等于退出。**
- 完全退出用 `⌘Q` 或菜单栏“退出时间便签”；填写表单时先保存或取消。

## 数据与统计含义

数据目录：`~/Library/Application Support/TimeNoteNative-v1/`。

主文件是 `timenote.sqlite`，运行时可能还有 `-wal`、`-shm` 文件。不要在运行时只复制主文件充当备份，优先使用应用的导出功能。移动应用不会移动记录，删除应用也不会自动清理数据。

- 数据库和导出备份**未额外加密**，请像私人文档一样保管。
- 没有云同步、遥测或主动上传；自行把备份保存到云盘时，云盘自身的同步不受本软件控制。
- 未记录单列，不当作 `0%`；没有计划的日子不作 `0%` 评价。
- 完成率按已记录工作的计划分钟加权：30 分钟完成 100%，90 分钟完成 50%，结果是 **62.5%**。跨午夜归开始日。
- 每次进展与单步撤销追加历史，不抹掉旧记录；已开始的安排不可修改。
- 初次打开为空清单，不读取其他软件的数据。

原生 JSON 格式为 `timenote-native` / 版本 `1`，与早期网页 Demo 的 JSON 不兼容。首版导入上限 20MB、20000 项工作、2000 个目标、200000 条历史；日期范围 2000–2100，一次重复区间最多 366 天，单段 1–1440 分钟。

## 当前限制

- **睡眠或主程序完全退出后的准时持续响铃尚未实现、尚未验证。** 不用普通通知冒充闹钟，也没有注册后台、登录启动或申请电源／通知权限。
- 还没有取消／归档工作、修改目标名称、网页备份迁移、自动更新、AI 或云同步。
- 回顾按打开页面时的最新数据计算；显示开关和分类筛选可用，自定义生成日期／时刻尚未接入。
- 系统备份文件对话框完整键鼠流程、全局快捷键跨应用触发、跨时区长期使用和压力测试尚未验收。

## 从源码构建

需要 Apple Silicon Mac、Swift 6.3.3 兼容的 macOS SDK 和 Python 3。当前验证环境使用已有的 Apple 命令行开发工具；脚本不会安装工具或更改系统设置。

在仓库目录内依次运行：

```sh
python3 fetch_dependencies.py
python3 -B Tests/ReleaseChecks.py
python3 build.py test
python3 build.py app
```

第一条会联网下载两个官方固定版本到 `Vendor/`，校验归档 SHA-256；不会上传源码或用户数据。后续构建和测试仅在本机执行，输出到 `.build-local/` 与 `dist/`。`Vendor/`、缓存、数据库、截图和安装包不进入 Git。

应用位于 `dist/时间便签.app`。可选 `python3 build.py icon` 重建图标。工程直接使用 `swiftc`，基础代码已包含在 `Sources/TimeNoteCore/`，不依赖仓库外文件，不需要 SwiftPM。编译将源码路径映射为 `/timenote`，避免发布二进制包含构建者的个人目录。

### 开发检查

- `Tests/NativeChecks.swift` 与 `Tests/ActionChecks.swift`：117项直接编译数据检查，保留原74项，并覆盖持续行动分组、同名不误合并、截至今天的积累、整组加入／换／移出、成员变化拒绝，以及真实SQL中途故障全部回滚；不是标准XCTest，也不替代上游完整测试。
- `Tests/ReleaseChecks.py`：5项检查，核对独立基础路径、公开版本与编译路径保护、持续行动界面和说明、MIT双署名及随包许可入口。
- `python3 build.py ui-app`：生成独立测试包，只有该包包含 `--data-dir` / `--smoke-test` 入口。测试数据目录必须是绝对路径且清单为空；加 `--dark --small` 检查深色小窗口。检查会打开本软件窗口、保存虚构数据截图并自动退出，不申请系统辅助功能权限。
- 本机1100×780浅色和940×690深色窗口两轮各通过27个检查点、保存19张虚构数据截图：包含原新增／取消／进度／修改预览流程，以及60次安排归为两项、部分归属仍保留完整组、整组加入与换目标、长名称六种旧归属可滚动查看、预览后刷新仍拒绝覆盖新进度、数据库重开。只向本窗口派发键盘与原生控件操作，不是完整系统级鼠标测试。
- 业务源码按警告即失败方式编译；GRDB 的两条上游 Any／Sendable 警告暂保留。
- 本版两轮窗口检查各有9条SwiftUI `AttributeGraph` 布局循环警告；历史检查也出现过系统输入法日志。两轮操作、截图和保存检查均通过，但不宣称运行日志无警告或所有环境都已验证。
- 打包时文件提供程序可能自动添加 Finder 元信息，导致工作目录内 `.app` 的严格校验提示异常；发布资产需另做解压／挂载后的严格完整性检查，不能拿普通校验代替。
